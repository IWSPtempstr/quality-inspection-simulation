# Phase 5 / I5 legacy runtime candidate inventory

Date: 2026-07-17

This inventory prepares the exact-file amendment that `DEV_SPEC.md` requires
before Phase 5 / I5 can delete the legacy runtime. It is evidence only: no
file listed here has been deleted by this audit.

The classification is intentionally conservative:

- `delete-candidate`: clearly part of the old FastAPI/Jinja/LangGraph/MCP/FAISS
  runtime that the production rebuild replaces.
- `keep-reference`: not part of the production runtime, but still useful as
  migration evidence, controlled fixtures, generated datasets, or user-owned
  documentation.
- `review-required`: may be legacy, but deleting it without a human-approved
  amendment would risk removing assets that still support validation, research,
  or migration evidence.
